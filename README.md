# OpsLens

Reliability and overload engineering for a Kubernetes-hosted
document-processing workload.

## Engineering objective

Evaluate and improve the behaviour of Gotenberg under mixed document
workloads, overload, resource constraints and controlled failures.

The project will establish a measurable baseline before introducing
workload isolation, autoscaling, observability and failure-response
improvements.

## Current stage

Stage 1 - Local workload characterization.
